# Simon Game

![Simon Game Screenshot](img/Simon%20Game.png)

This is a web-based **Simon Game**, a classic memory and pattern-matching game. It's built with basic web technologies to demonstrate core JavaScript logic and DOM manipulation. The game challenges players to remember and repeat a sequence of flashing colors that grows with each round.

---

## 🧠 How to Play

1.  **Start the Game**: Click the "Start" button to begin. The game will flash a random color.
2.  **Follow the Sequence**: Click the color you saw.
3.  **Advance to the Next Level**: If you click the correct color, the game will add another random color to the sequence. The goal is to remember and repeat the entire, growing sequence.
4.  **Game Over**: If you click the wrong color at any point, the game ends. Your score is the level you reached. Click "Start" to play again!

---

## ✨ Features

* **Classic Gameplay**: Recreates the core logic of the original Simon game.
* **Level Progression**: The game automatically increases the difficulty by adding one new color to the sequence with each successful round.
* **Visual Feedback**: The buttons flash to indicate both the computer's turn and your button presses.
* **Simple UI**: A clean and straightforward interface built with basic HTML and CSS.

---

## 🛠️ Technologies Used

* **HTML5**: For the basic structure and layout of the game.
* **CSS**: For styling the game's appearance, including the colored boxes and flash effects.
* **JavaScript**: The core language that handles all game logic, from generating sequences to checking user input and managing game state.
